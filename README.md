# wow-create

WoW 无限服（部落 PvP）角色创建重试器：macOS 原生菜单栏 + Dock 应用，只在本机运行。

## 当前能力

状态机按画面自动推进，不依赖固定等待：

| 识别到的界面 | 动作 |
| --- | --- |
| 登录界面（重新连接/退出） | 点“重新连接” |
| 普通服务器角色列表 | 点顶部“规则集” |
| 规则集选择 | 选中 PvP → 点“选择” |
| 角色创建 | 男性 → 部落·亡灵 → 牧师 → “自定义外观” |
| 命名界面 | 主名输入框清空并输入 `ask`，副名输入框清空并输入 `timemachine`，点“完成” |
| 阵营不平衡弹窗 | 点“确定”，随后退回登录界面重试 |
| 失败回退 | 命名/创建界面点“后退”，PvP 角色列表点左下方“后退” |

- 菜单栏 `W` 图标点击打开控制面板，面板吸附在该图标下方；Dock 图标点击同样打开。
- 自动化运行中打开面板会自动暂停输入（不会误判成焦点切出）；关闭面板并回到 WoW 后继续。
- 全局停止键默认 `⌃⌥⌘⇧K`（避开旧默认 `⌃⌥⌘K` 与 mole 的冲突），可在面板里重录。
- 只在前台投放输入：`CGEventPost(kCGHIDEventTap, ...)`，不使用 `CGEventPostToPid` 后台注入。
- WoW 失去前台焦点立即停止；启动后 3 秒内切回即可。
- 安全上限：30 轮 / 40 次失败弹窗 / 400 次操作 / 30 分钟。
- 点击间隔 0.9–1.5 秒随机、坐标 ±2pt 抖动、按下 55–105ms、鼠标移动分 4 段插值。
- 名字只接受小写字母和数字（`[a-z0-9]`），空值回落到默认名。

## 构建

```bash
./Scripts/build.sh          # 产物 build/WoWCreate.app
./Scripts/test-classify.sh  # 画面分类回归（需要 Tests/fixtures 里的 9 张截图）
```

编译只需要 Command Line Tools 的 `clang`，不依赖完整 Xcode；工程是 Objective-C + AppKit/Quartz。

首次运行需要在 系统设置 → 隐私与安全性 → 辅助功能 中勾选 WoWCreate，并授予屏幕录制权限（读取 WoW 窗口截图）。

## 状态判定

全部使用窗口截图内的归一化矩形 + 颜色统计，不硬编码 1660×1094 绝对像素，也不读取游戏内存：

- 失败弹窗：屏幕中部“确定”的红字带红色占比 > 0.30。
- 登录界面：中部红色“重新连接”按钮红色占比 > 0.40。
- 规则集选择：左下“取消”和右下“选择”同时 > 0.50。
- 角色创建：部落红色竖条 > 0.20。
- 普通角色列表：底部中央红色“进入世界”> 0.45。
- PvP 角色列表：左下“后退”> 0.50 且“创建角色”> 0.50。
- 命名界面：底部左右两个红按钮 > 0.50，且主名输入框区域亮度 < 45。

阈值由 9 张实机截图回归确定，`Tests/classify_test.m` 会逐张校验；缺图记为 `SKIP`，不记为通过。

## 成功判定

点击“完成”后：

- 出现失败弹窗 → 清空提交标记，走失败回退，不算成功。
- 未出现弹窗、直接回到角色列表 → 停止，状态显示“疑似创建成功”。
- 命名界面 12 秒不变 → 最多重试“完成” 4 次，仍无变化则停止。

因为目前没有成功截图，成功判定是保守近似；停止后请以角色列表里是否出现 `ask` 为准。

## 已知限制

- 坐标按 1660×1094（含标题栏、宽高比约 1.52）的窗口标定。换分辨率/宽高比或全屏后需要重新标定 `FlowProfile.m`。
- 游戏界面皮肤大改、按钮颜色变化会导致识别失败；面板会显示“未识别当前界面”。
- 每次重新构建未签名二进制后，macOS 可能要求重新勾选辅助功能权限。
- 未实现账号密码输入、后台注入、反检测绕过；不做任何隐藏进程或内存修改。
