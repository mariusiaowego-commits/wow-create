# wow-create

WoW 无限服角色创建辅助：macOS 原生菜单栏 App，只在本机运行。

## 功能

- 菜单栏 `W` 图标点击打开控制面板，面板吸附在菜单栏图标下方。
- Dock 图标点击同样打开控制面板；关闭面板只是隐藏，不退出 App。
- 自动截取 WoW 窗口（不抢焦点），识别“创建”按钮红/灰状态与阵营不平衡弹窗。
- 红按钮时点击右下角“完成”；失败弹窗出现后按 Enter/点击“确定”。
- 成功自动停止需要额外的“成功画面/角色列表”证据；当前版本不会猜测成功，因此该验收项暂未实现。
- 保守成功检测默认开启：点击创建后，如果创建角色界面与红色/灰色按钮同时消失超过约 3 秒，会自动停止，避免继续误点。可在菜单关闭该检测。
- 全局停止键默认 `⌃⌥⌘K`，面板里点“停止键”可重新录制任意组合键；若与 mole 等工具冲突，改成不冲突的组合即可，设置会持久化。
- 菜单栏/Dock 的“停止自动化”按钮也可随时停止接管。
- 可配置角色名和服务器名；不会猜测、不会猜测成功状态。

## Build

```bash
./Scripts/build.sh
```

产物：`build/WoWCreate.app`。首次运行需要授予辅助功能权限（System Settings → Privacy & Security → Accessibility）。

## 状态检测

默认使用相对坐标 + ROI 颜色检测：

- 创建按钮：`x=0.79..0.97, y=0.91..0.97`，红色占比高且灰色占比低时点击。
- 失败弹窗确定按钮：`x=0.42..0.58, y=0.55..0.62`，出现红色按钮时关闭弹窗。

不同分辨率/缩放需通过设置里的 ROI 调整；App 不硬编码 1660×1094 绝对坐标。
