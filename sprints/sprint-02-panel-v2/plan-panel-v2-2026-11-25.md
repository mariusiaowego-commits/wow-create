# 计划

## 目标

菜单栏面板改成完整单界面，可长期驻留在 WoW 旁边监控运行状态；本轮只做本地 git 发布，不推送 GitHub。

## 范围

- 无标题栏圆角面板，去掉关闭/最小化按钮。
- 失焦、点面板外、切换 App 自动收起；自动化运行期间例外，面板常驻且不抢 key。
- 面板底部显示当前/磁盘版本与构建时间，附辅助功能、屏幕录制实时状态。
- 状态栏图标改为模板符号，深色菜单栏可见；点击图标切换面板，面板按点击所在屏锚定。
- 面板可拖动并记住位置（`PanelCustomFrame`）。
- 状态信息对比度：强制深色外观，状态行白色加粗，识别/计数/版本用固定灰阶。
- 版本号升到 `0.2.1`，本地打 tag。

## 验收

1. `./Scripts/build.sh` 成功，Info.plist 版本 `0.2.1`。
2. 分类回归 9/9。
3. 截图确认状态文字可读、无标题栏按钮、版本行三行完整。
4. 运行中面板保持可见，WoW 仍为前台（不抢 key）。

## 非目标

- 真机建号成功判定（仍缺成功样本）。
- 签名稳定化（ad-hoc 签名每次重建会使 TCC 授权失效，本轮仅记录）。
